# DevProxy 2.3.4 — отчёт проверки и ограничения

Завершены исправления туннеля, сохранённых профилей, CLI и диагностики. Добавлены резервные маршруты из сохранённых профилей и отдельный браузер входа Antigravity. Старые соединения не перезапускаются при обычном редактировании профиля; переименование сохраняет постоянный идентификатор и порт.

TLS проверяется штатным SSLContext. Ошибки сертификата и отказ белого списка не обходятся. Автоматические повторы ограничены первичным TLS-рукопожатием; резервный сервер выбирается только до CONNECT и отправки прикладных данных. Генерации и другие отправленные действия не воспроизводятся.

Браузер входа использует отдельный профиль и тот же мост. Свежий OAuth URL можно прочитать из локального журнала установленного клиента 2.11.0 либо вставить вручную. URL с параметрами не сохраняется в состоянии и не печатается в логах DevProxy. После открытия браузера выход закрепляется до завершения сессии. Прямой браузер по умолчанию не перенастраивается.

Группа поддерживает основной профиль и до четырёх резервных, без придуманных адресов или учётных данных. Чтобы использовать пять серверов, нужно сохранить их реальные параметры в GUI. Автоматическая цепочка российского входа и зарубежного выхода не реализована: российский профиль должен представлять уже настроенный маршрут. Прямого fallback у локального моста нет. Приложения, игнорирующие native/environment proxy, могут подключаться напрямую; WFP-драйвер и системная служба не входят в эту сборку.

Проверки сборки выполняет tools/build_windows.py: полный unittest discover, compileall, Windows CLI/GUI PyInstaller, CLI help, CLI UI smoke и GUI smoke, упаковка ZIP и SHA256SUMS. Итоговые команды, число тестов и живые проверки указываются в REVIEW_REPORT.md в каталоге передачи. Интерактивные OAuth, список моделей и ответ на сообщение считаются подтверждёнными только при наличии соответствующего результата; TLS/CONNECT 200 не заменяет такую проверку.

## Подтверждение выпуска 7 октября 2026

Локально прошли 175 автоматических тестов, сборка Windows CLI/GUI и проверки запуска упакованных EXE. После установки пользователь подтвердил, что Antigravity отвечает, и разрешил публикацию. Это подтверждение ответа модели; вход и полный сценарий при отключённом VPN отдельно не проверены. В тестовом запуске наблюдались отдельные TLS EOF на этапе подключения к HTTPS-прокси. Подробный публичный отчёт: [docs/RELEASE_VERIFICATION.md](docs/RELEASE_VERIFICATION.md).
