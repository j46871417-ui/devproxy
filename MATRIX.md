# Поддержка DevProxy 2.3.8 для Windows

| Режим | Что работает | Ограничения |
| --- | --- | --- |
| Antigravity | Обычный профиль, proxy flags, окружение потомков, локальный интерфейс без внешнего прокси | Не гарантирует перехват произвольного внешнего трафика |
| Electron IDE | Однократные сессии; постоянные ярлыки используют обычный профиль | Старый процесс нужно закрыть перед первым запуском с прокси |
| CLI и произвольный EXE | Окружение прокси, реальный EXE/Node entrypoint, постоянные пользовательские ярлыки | Программа может игнорировать окружение |
| Фоновый агент | Трей, автозапуск текущего пользователя, запуск через защищённый named pipe, сохранённые локальные порты | Пользовательская сессия Windows; не системная служба |
| Постоянные правила | Ярлыки рабочего стола, пользовательского Пуска и TaskBar; журнал восстановления | Прямые EXE, общие ярлыки и файловые ассоциации не перехватываются |
| Отмена | Восстановление исходных ярлыков и автозапуска; сохранение чужих изменений | Конфликтующие изменения требуют ручного решения |
| WFP / полная изоляция | Строгий режим явно отказывает | Backend принудительного маршрута не реализован |

HTTP forward/CONNECT, HTTPS proxy TLS, SOCKS5 authentication и remote DNS, IPv4/IPv6 кодирование проверяются локальными тестами. Только локальные адреса обходят туннель по настройкам запуска: это нужно для внутреннего интерфейса IDE. Сам туннель не делает direct fallback к внешней цели. JobObject управляет временем жизни процессов, а не маршрутом сети.

## Проверка текущего выпуска

| Сценарий | Подтверждение | Предел проверки |
| --- | --- | --- |
| Восстановление окна standalone Antigravity | Настоящий loopback timeout -7, автоматический повтор 1/2, HTTP 200 и загруженный интерфейс | Только совместимый ASAR; первичная задержка не устранена |
| Статус постоянного режима | Регрессии включения/отключения/неизвестного состояния; назначенные профили и отдельный статус агента | Включённое правило не доказывает доступность API |
| Полный build gate | 203 локальных теста, compileall, CLI/GUI EXE smoke checks | Не универсальная проверка всех обнаруженных IDE |
| Рабочее состояние после установки | Подтверждено пользователем 8 октября 2026 | Новый OAuth без VPN и все внешние сервисы отдельно не проверены |
| Белый список назначения upstream | Отказ назначения явно возвращается; direct fallback отсутствует | Разрешения сервера DevProxy не расширяет |
