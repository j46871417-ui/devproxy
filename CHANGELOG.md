# DevProxy 2.3.2

Windows-выпуск с русским интерфейсом, автоматическим поиском IDE и инструментов, редактированием профилей и вставкой из буфера обмена.

- Исправлен чёрный экран Antigravity: локальный интерфейс остаётся на loopback, сохраняется пользовательский профиль.
- Фоновый агент, значок в трее, закрытие окна без остановки прокси и запуск при входе в Windows.
- Постоянные правила через пользовательские ярлыки, с восстановлением обычного запуска.
- Убрана обязательная проверка github.com перед запуском: работают прокси со списком разрешённых сайтов, если сервисы выбранной IDE разрешены.
- HTTP, HTTPS-прокси и SOCKS5; пароли в Windows Credential Manager, без включения личных настроек в релиз.

Распакуйте `devproxy-windows-x64.zip` в постоянную папку и запустите `devproxy-gui.exe`. Для проверки загрузки опубликован `SHA256SUMS.txt`.

DevProxy передаёт настройки прокси приложениям. Полный перехват трафика через WFP и гарантированная блокировка прямых подключений не реализованы. Доступ к сайтам определяет ваш прокси; запреты его белого списка не обходятся. Исполняемые файлы пока не подписаны сертификатом издателя.

Проверено: 116 автоматических тестов, сборка Windows CLI/GUI, запуск готовых EXE и native Windows tray/IPC/ярлыки. Работу Antigravity подтвердил пользователь.
