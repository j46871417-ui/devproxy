# Проверка DevProxy 2.3.4

7 октября 2026. Локальная Windows-сборка: Python 3.14, PyInstaller, 175 автоматических тестов (без ошибок и пропусков), compileall, CLI --help, CLI --self-test-ui, GUI --self-test. Вся сборка завершилась с кодом 0. Публикация по тегу дополнительно запускает workflow Windows validation and release.

Установленный агент 2.3.4 использован для четырёх HTTPS-проверок: daily-cloudcode-pa.googleapis.com, cloudcode-pa.googleapis.com, accounts.google.com, oauth2.googleapis.com. Каждый CONNECT вернул 200, TLS 1.3 проверен штатным SSLContext, получены HTTP-ответы и прочитаны тела. Корневые ответы 404/302 подтверждают транспорт, а не авторизацию API.

В наблюдённом запуске установленного Antigravity 2.11.0 зарегистрировано 15 успешных туннелей и 4 начальных SSLEOFError на этапе proxy_tls; одна ошибка назначения осталась в состоянии диагностики. Журнал language server содержал 3 Bad Gateway. Все установленные TCP-соединения language server в двух снимках были loopback; прямых внешних соединений в этих снимках не было. Это не является гарантией перехвата любого будущего трафика.

После установки пользователь подтвердил фактический ответ Antigravity и разрешил публикацию. Вход и полный сценарий при отключённом VPN отдельно не подтверждены; состояние VPN в ходе проверки не менялось. Доступ к аккаунту и серверам Google зависит также от выбранного прокси, разрешённых назначений и аккаунта.

Проверено отсутствие сохранённых паролей в исходниках, финальных локальных логах и архиве: 3 профиля с секретами, 58 объектов, 0 совпадений. Установленные EXE совпадали по SHA256 с проверенной локальной сборкой. В релизе нет пользовательского состояния, профилей, паролей, OAuth URL, журналов клиента и резервных копий. CI может пересобрать EXE с другими хешами; итоговые хеши файлов конкретного релиза приведены в его SHA256SUMS.txt.

Приложение использует native/environment proxy, не WFP-перехват. Сам мост не подключается напрямую вместо прокси; программы, игнорирующие переданные настройки, могут обходить его. Проверка сертификатов, HTTP 403/407 и белые списки назначений не обходятся. EXE не подписаны сертификатом издателя.
